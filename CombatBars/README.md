# CombatBars

Shows action bars 1 and 2 only in combat. Out of combat they're hidden, which keeps the screen clean.

- The bars also show in a vehicle, on an override or possess bar, and in pet battles.
- While a spell, item or macro is on your cursor, the bars show so you can drop it on a slot.
- Keybinds still work while the bars are hidden.

## Commands
| Command | What it does |
|---|---|
| `/combatbars` | Toggle on or off |
| `/combatbars on` / `/combatbars off` | Set it explicitly (lasts until `/reload`) |

## Setup
In Edit Mode, set bar 2's visibility to **Always**. Its own "In Combat" option would hide it again out of combat.
