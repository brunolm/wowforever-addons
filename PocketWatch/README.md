# PocketWatch

A small stopwatch box. By default it sits under TomTom's coordinate box (or the minimap if TomTom isn't installed).

- **Left-click:** start or pause. The text turns grey when paused.
- **Right-click:** stop and reset.
- **Drag:** move it anywhere. The position is saved.
- The time survives `/reload` and logout. If it was running, it keeps counting real time while you're logged out.

## Commands
| Command | What it does |
|---|---|
| `/pw` | Show or hide the stopwatch |
| `/pw start`, `pause`, `reset`, `toggle` | Control the timer |
| `/pw show`, `hide` | Show or hide it |
| `/pw resetpos` | Put it back in the default spot |
| `/pw options` | Colors for running text, paused text, border and background, with opacity (also under Options > AddOns > PocketWatch) |

`/pocketwatch` works the same as `/pw`.
